# Handy per WLAN-adb verbinden (optional – ohne das laeuft IntruderWatch per USB-Kabel)
# Mac und Handy muessen im selben Netz sein. Die Handy-IP im Router fest reservieren
# (DHCP-Reservierung), sonst stimmt PHONE_WIFI irgendwann nicht mehr.

# 1) Handy einmal per USB anstecken, USB-Debugging zulassen. Dann am Mac:
adb devices                    # <SERIENNUMMER>  device
adb tcpip 5555                 # schaltet adb ueber WLAN ein (Port 5555)
adb connect <HANDY-IP>:5555
adb devices                    # <HANDY-IP>:5555  device  -> Kabel darf ab

# 2) In ~/Library/IntruderWatch/config.sh eintragen:
#      : "${PHONE_WIFI:=<HANDY-IP>:5555}"
#    Leer lassen = nur Kabel (USB-Modus).

# Nach einem Handy-Neustart ist der WLAN-Modus aus. Einfach das Kabel kurz
# anstecken: der Gesundheits-Check (alle 30 min) macht `adb tcpip 5555` + connect
# selbst. Sofort von Hand:  bash ~/Library/IntruderWatch/intruder-health.sh
# (oder Schritt 1 wiederholen).

# Pruefen:  bash ~/Library/IntruderWatch/intruder-health.sh --report
#           -> "Handy: erreichbar (<HANDY-IP>:5555)"

# Sicherheit: Solange der WLAN-Modus an ist, ist adb im lokalen Netz erreichbar
# (neue Rechner muessen am Handy bestaetigt werden). Nur in vertrauenswuerdigen
# Netzen nutzen, nicht in oeffentlichem WLAN.

# Hinweis Foldables (z. B. Galaxy Z Fold): zwei Displays. Screenshots dann mit
# Display-ID, sonst landet eine Warnung in der PNG:
#   adb shell dumpsys SurfaceFlinger --display-id
#   adb exec-out screencap -d <DISPLAY-ID> -p > screen.png
